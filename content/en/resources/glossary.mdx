# Glossary

**Agent** — A specialized AI tool built on X-Agent that executes tasks autonomously on a user's behalf.

**Speak to Build** — Creating an Agent by describing it in natural language, with no code.

**Share to Connect** — Distributing an Agent across the Web3 social graph so it can connect users and services.

**Business Mining** — The three-dimensional reward model: Execution Mining, Distribution Mining, and Value Mining.

**Super-Agent** — A high-adoption Agent that attracts large numbers of active users.

**Relationship Mapping** — X-Agent's use of authentic Web3 social protocols to recognize a user's real-world network for task execution.

**$XAGT** — The native gas and commission settlement token of the ecosystem.

**TGE** — Token Generation Event, when $XAGT is first minted and circulated.
