# XAGT概要

**$XAGT**は、X-Agentエコシステムのネイティブトークンです。計算処理、ステーキングによる支持、エージェントが仲介する商取引におけるガスおよび手数料の決済レイヤーとして機能します。

| **シンボル**             | $XAGT                                                                       |

| **役割**                 | ガスおよび手数料の決済レイヤー                                              |
| **獲得方法**             | 3次元の[Business Mining](/ja/litepaper)（Execution / Distribution / Value） |
