# トークン配分およびベスティングスケジュール

`ステータス：暫定版 · 2026年9月7日公開`

これはコミュニティ内で合意に達したトークン配分です。プロジェクトチームは現在も取引所および有力投資家と協議を続けているため、配分および初期供給量は、取引所および投資家との合意内容に基づき変更される可能性があります。コミュニティとの認識を適時一致させるために情報を継続的に更新し、TGE前に最終決定します。

| カテゴリー     | 配分     | 主なベスティングスケジュールおよびリリース条件                                                                                                                                                                                  |
| -------------- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| コミュニティ   | 58%      | TGE時に2%をアンロックし、残りの56%を8四半期にわたりマイニングを通じて線形に配分します。                                                                                                                                          |
| マーケティング | 14%      | TGE時に4%-8%をアンロックし（CEXとの調整による）、残りの6%-10%をQ1-Q8にわたりアンロックします。主要取引所から要請があった場合、プロジェクトの流動性を高めるため、チームは最大5%を当該取引所向けにアンロックする権利を留保します。 |
| エコファンド   | 8%       | TGE時に1%をアンロックし、残りの7%を5四半期にわたり配分します。                                                                                                                                                                  |
| チーム         | 10%      | TGE時のアンロックは0%です。12か月のクリフ期間後、残りの10%をQ5-Q12（8四半期）にわたりアンロックします。                                                                                                                         |
| マーケットメイキング／流動性 | 4.5%     | 初期流動性を確実に管理するため、TGE時に2.5%をアンロックし、残りの2%を5四半期にわたり配分します。                                                                                                                               |
| 投資家         | 5.5%     | TGE時のアンロックは0%です。12か月のクリフ期間後、残りの5.5%をQ5-Q12（8四半期）にわたりアンロックします。                                                                                                                        |
| **合計**       | **100%** | **TGE時の初期総流通量：9.5%-13.5%**                                                                                                                                                                                              |

</div>

コミュニティに配分された58%のうち、約29%をユーザー向け、残りの約29%をその他すべてのビルダーおよびパートナー向けとします。
